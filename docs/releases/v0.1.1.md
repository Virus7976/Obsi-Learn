# ObsiLearn 0.1.1

- New app icon: a graduation cap made of glass. All four Obsi apps now have icons of the same family.
- Home servers work: a NAS or PC that uses plain http (like `http://192.168.1.20:8080/Courses`) can now be added. Before, the app refused every http address.
- If you type https and the server only speaks http, ObsiLearn tries http by itself and tells you.
- Errors when adding a source are now in plain words, with what to check.
- A new README with pictures of the app.
