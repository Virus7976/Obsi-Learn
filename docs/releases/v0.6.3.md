# ObsiLearn 0.6.3

- **One folder for all Obsi apps.** Course and podcast notes now go in Obsi/ObsiLearn in your vault. The notes in your old ObsiLearn folder move there by themselves, once. A note already there is never written over.
- **Unfollow a podcast, and its note goes too.** The note moves to Obsidian's trash folder (.trash), so you can still get it back. Removing a course does the same.
- A template that saved to Clippings now saves to Obsi/ObsiLearn. Change it in Settings, Obsidian, Templates.
- To rename the Obsi folder: Settings, Obsidian, Folder.
