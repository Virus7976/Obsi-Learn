# ObsiLearn 0.6.2

- **Files read like ObsiRead.** A PDF or document as text now has the same bar along the bottom: your highlights, how much is left, Listen, reading settings, and Clip to send your highlights to Obsidian.
- When a file has headings, tap the time left to see them and jump to one.
- At the top: find in the file, and ⋮ with quick buttons you pick.
- Reading settings change the font, size, spacing and colours of the text.
- A new file no longer shows the player of a file you paused before.
